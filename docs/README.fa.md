# ProxyGosha — مستندات فارسی

مستندات اصلی و کامل فارسی در ریشه مخزن است: **[README.md](../README.md)**

این فایل از نسخه 1.3.0 به بعد فقط به سند اصلی اشاره می‌کند تا دو نسخه فارسی از هم جدا نیفتند.

## خلاصه v1.3.0

- سکرت مستقل `SECRET` (توصیه‌شده) + هشدار و مقدار فریز در حالت legacy (فقط `ADMIN_KEY`)
- ورود پنل با کوکی از `/login`؛ مسیر کلید در URL منسوخ شد
- توکن‌های وابسته به host با عمر ۶ ساعت + `KEY_EPOCH` برای ابطال انبوه
- جداسازی سخت پورت‌ها (`LEGACY_PORT_SECRETS=1` برای رفتار قدیمی)
- batching واقعی آپ‌استریم 256KiB، اتصال پله‌ای DC با حافظه last-good
- سکرت اختصاصی کاربران (`USER_SECRETS`)، QR/کپی/تست تأخیر در پنل، `DC_OVERRIDE`، `ALERT_URL` اختیاری
- حذف `AD_TAG`، `GENERATOR_ENABLED`، `GENERATOR_KEY`، `ACCEPT_GENERATED` (تحلیل ME: `ME-notes.md`)

راهنمای کامل راه‌اندازی، مرجع همه متغیرهای env، عیب‌یابی و پرسش‌های متداول: **[README.md](../README.md)**
